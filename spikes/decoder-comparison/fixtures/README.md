# Deterministic QR regression corpus

All PNGs in `generated/` are produced by `qrforge-decoder-comparison` from
synthetic payloads and programmatic backgrounds. They contain no personal data,
third-party screenshots, credentials, or trademarks and may be regenerated by
running the release benchmark.

The corpus contains generated symbols plus deterministic screen-like
transformations:

- URL, plain-text, malformed URL-like, dangerous-scheme, Unicode, and binary payloads
- multiple-code, inverted, low-contrast, downscaled, rotated, perspective, blurred, and partially obscured symbols
- browser-rendered, screenshot-compressed, colored, high-DPI, small-on-high-resolution, and dense-UI compositions
- a no-code patterned image used to guard against false positives

The saved `colored.png` is RGB; benchmark engines receive the same deterministic
luminance conversion while the production adapter regression test reads the
actual colored PNG. `perspective.png` is deliberately retained as the sole
accepted ZXing-C++ failure. The benchmark exits unsuccessfully if that known
failure set changes, so unexpected regressions fail CI without weakening the
fixture.
